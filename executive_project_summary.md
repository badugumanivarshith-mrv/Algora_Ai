## 1. PROJECT ABSTRACT & MOTIVATION
Algora was built to solve the fundamental disconnect between static academic computer science education and practical industrial software engineering requirements. Traditional learning platforms rely on passive video lectures and static quizzes, while corporate hiring depends on verified problem-solving speed, debugging capability, and system design competence.

---

## 2. KEY ACHIEVEMENTS & METRICS
*   **Database Optimization:** Modeled 45 relational PostgreSQL tables with B-Tree indexes, achieving a **99.4% query index hit rate** and P95 latencies under 11.4ms.
*   **AI Cost Control:** Engineered an MD5 prompt-hashing cache layer in Redis, reducing duplicate Gemini LLM API expenses by **45%**.
*   **Zero-Trust Security:** Hardened authentication with Google OAuth (PKCE), HTTP-Only secure cookies, and timing-safe cryptographic comparisons (`crypto.timingSafeEqual`).
*   **Proven Usability:** Achieved an exceptional **88.5 SUS Usability score** (Grade A+) and a **+72 Net Promoter Score** across active test cohorts.
