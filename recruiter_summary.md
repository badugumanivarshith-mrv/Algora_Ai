## 🚀 Executive Summary
Algora is a production-grade, full-stack educational and recruitment platform built with **React 19**, **Node.js/Express**, **PostgreSQL**, and **Redis**. It demonstrates end-to-end engineering competence, from responsive frontend UI design to secure backend API gateways, database optimization, and AI cost-control engineering.

## 🔑 Key Engineering Achievements
*   **Performance Optimization:** Achieved a **99.4% database query index hit rate** across 45 PostgreSQL relational tables with P95 latencies under 11.4ms.
*   **AI Cost Control:** Engineered an MD5 prompt-hashing cache layer in Redis that reduced duplicate Gemini LLM API expenses by **45%**.
*   **Zero-Trust Security:** Hardened authentication with Google OAuth (PKCE), HTTP-Only cookies, and constant-time cryptographic verification (`crypto.timingSafeEqual`).
*   **Scalable Containerization:** Configured multi-stage Docker builds packing the server into a slim CommonJS bundle (`dist/server.cjs`) under 200MB for Google Cloud Run.
