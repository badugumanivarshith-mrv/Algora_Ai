# Contributing to Algora

First off, thank you for considering contributing to Algora! It's people like you that make Algora such a powerful tool for computer science students and educators.

## Code of Conduct

By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).

## How Can I Contribute?

### Reporting Bugs

- **Search first** to see if the bug has already been reported.
- If you can't find an open issue, create a new one. Choose the **Bug Report** template.
- Include a clear title, description, steps to reproduce, expected behavior, and screenshots if applicable.

### Suggesting Enhancements

- **Check if it has already been suggested.**
- Create a new issue using the **Feature Request** template.
- Explain the problem, proposed solution, and why it's useful to the project.

### Pull Requests

1. **Fork** the repository.
2. Clone your fork locally.
3. Create a new branch: `git checkout -b feature/amazing-feature`.
4. Make your changes and commit them with descriptive commit messages.
5. Push to your branch: `git push origin feature/amazing-feature`.
6. Open a **Pull Request** against our `main` branch.

## Development Setup

See the installation instructions in the [README.md](README.md) to get your local environment running. Ensure all tests pass and there are no linting issues before committing:

```bash
npm run build
npm run lint
```
