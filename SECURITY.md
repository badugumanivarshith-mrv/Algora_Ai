# Security Policy

## Supported Versions

Only the latest release of Algora is actively supported with security patches:

| Version | Supported          |
| ------- | ------------------ |
| v5.1.x  | :white_check_mark: |
| < v5.1  | :x:                |

## Reporting a Vulnerability

We take the security of Algora seriously. If you find a security vulnerability, please do not report it publicly via GitHub issues. Instead, follow these steps:

1. Send an email to the security team or maintainers.
2. Describe the vulnerability, including step-by-step instructions to reproduce.
3. Allow up to 48 hours for a response acknowledging the report.
4. We will work to release a patch and coordinate a public disclosure window.
