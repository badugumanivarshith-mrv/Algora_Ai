## 1. PRE-FLIGHT TECHNICAL CHECKLIST

Before stepping in front of an evaluation panel, review this checklist to ensure smooth presentation execution:

- [ ] **Live App URL Accessible:** Verify that the development or production deployment URL loads instantly without gateway timeout errors.
- [ ] **Database Connectivity Active:** Ensure PostgreSQL and Redis connections are established and responsive.
- [ ] **Google OAuth Credentials Valid:** Verify that OAuth redirect URIs and API keys are correctly configured in environment variables.
- [ ] **Gemini API Key Verified:** Confirm that `GEMINI_API_KEY` is active and responsive for Socratic AI tutoring queries.
- [ ] **Browser Cache Cleared:** Test the login and dashboard flows in an incognito browser window to ensure a clean first-time user experience.
- [ ] **Backup Offline Fallback Verified:** Confirm that Redis in-memory fallback and local error handlers are operational if network issues occur.
